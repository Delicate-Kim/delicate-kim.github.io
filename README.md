# Personal Portfolio Website

This repository contains a clean, responsive personal portfolio website scaffolded to help migrate from an existing WordPress portfolio.

## Project Structure

- `index.html` - Main single-page portfolio
- `styles.css` - Visual design and responsive layout
- `script.js` - Small client-side interactions
- `wordpress-migration-checklist.md` - Step-by-step content migration guide

## Quick Start

Open `index.html` directly in your browser, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize Your Portfolio

1. Replace placeholder text (`Your Name`, bio, project descriptions, etc.) in `index.html`.
2. Update project cards and categories in the "Featured Work" section.
3. Add your own social/contact links in the Contact section.
4. Adjust brand colors in `styles.css` under `:root`.
5. Follow `wordpress-migration-checklist.md` to map over your existing WordPress content.
